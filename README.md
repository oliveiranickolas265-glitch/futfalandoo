# Site de futebol — GitHub Pages

## Estrutura
- `index.html`: página inicial (na raiz, necessária para abrir o site).
- `*.html`: páginas do site.
- `*.css`: folhas de estilo.
- `imagens/`: imagens, escudos, banners e demais arquivos visuais.
- `formulario/`: arquivos específicos da página de formulário.

Os caminhos das imagens nos HTML e CSS foram atualizados para apontar para `imagens/`.

## Publicar no GitHub Pages
1. Extraia este ZIP.
2. Envie todo o conteúdo para a raiz de um repositório GitHub.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`, depois clique em **Save**.

O site é estático. Recursos que dependam de servidor, banco de dados ou processamento de pagamentos precisam de configuração adicional.
